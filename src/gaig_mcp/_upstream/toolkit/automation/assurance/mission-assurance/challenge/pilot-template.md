# Mission Assurance Challenge Template

Synthetic template. Populate it privately for a real review. This file contains no measured results.

Automated output does not select a consequential disposition.

## Required record

- Mission objective
- Current baseline and comparator
- Acceptance criteria established before evaluation
- Resource assumptions
- Authority owners
- Data owners
- Delivery time
- Recovery result
- Relief result
- Exceptional intervention
- Support burden
- Failures and rejections
- Material changes
- Final human disposition

## Allowed final dispositions

- CONTINUE
- CONSTRAIN
- REMEDIATE
- TRANSFER
- RETIRE
- HOLD

The accountable institution selects the disposition. A profile result does not.
